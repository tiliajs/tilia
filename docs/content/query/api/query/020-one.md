`one` reads the first value after the configured `sort`. The read is reactive and shares the query's cached entry with every other reader.

An empty complete answer becomes `NoData({NoMatch({claim})})`; [array](api.html#array) instead returns a loaded empty array. The absence carries its [Claim](api.html#claim-type), so it can age like any other answer.

```typescript
// The card under review: the first of the deck per `sort`. A deck with nothing
// left is `noMatch`, and it says so with the claim its rows would have had, so
// the view can tell "done" from "done as of last sync".
const review = () => {
  const next = cards.one({ deck: "spanish" });
  if (next === "loading") return spinner();
  if (next.state === "loaded") return flashcard(next.data);
  if (next.reason === "offline") return offlineNotice();
  return next.reason.reason === "noMatch" ? deckDone(next.reason.claim) : failure(next.reason.message);
};
```

```rescript
// The card under review: the first of the deck per `sort`. A deck with nothing
// left is `NoMatch`, and it says so with the claim its rows would have had, so
// the view can tell "done" from "done as of last sync".
let review = () =>
  switch cards.one({deck: "spanish"}) {
  | Loading => spinner()
  | Loaded({data: card}) => flashcard(card)
  | NoData({reason: Offline}) => offlineNotice()
  | NoData({reason: NoMatch({claim})}) => deckDone(claim)
  | NoData({reason: Failed({message})}) => failure(message)
  }
```
